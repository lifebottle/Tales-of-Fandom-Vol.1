# Tales-of-Fandom-Vol.1 (Cless Version)
An attempt to create an English patch for Tales of Fandom Vol. 1 on the Playstation.

Extraction Step 1 CDmage
double click on the CDmage program in tools/CDmage
Drag the cue file from the game to the open window of CDmage
Click on Track 1, the files will appear on the right in the program
select all the files and right click extract
A context window will open, extract to the repo 0_disc folder

Extracting the Content of the TOF file
Double click the extract bat or run python tools/codebase/untof.py
